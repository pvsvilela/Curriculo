# Curriculo

## Como testar localmente

1. Instale as dependências básicas do Python (qualquer versão 3.x já traz o servidor HTTP).
2. Dentro da pasta do projeto, execute:

   ```bash
   python3 -m http.server 4173
   ```

3. Abra o link gerado no navegador: [http://localhost:4173](http://localhost:4173).

Esse endereço carrega o `index.html` diretamente, permitindo navegar pelo portfólio/viagem de trem e validar as animações exatamente como ficarão em produção.
